## Explanation of this proposal

The cloud is a large network of remote servers that can be accessed over the internet for storing and managing data, running applications and delivering services. This allows for you to access your data from any internet-device without needing to manage the servers themselves or store everything on a personal/work computer.

## Questions to ask about the proposal

* Where will the data physically reside, which countries would that data be in and does it comply with the national and regional protection laws?
* Is all data encrypted at rest and in transit?
* Can we ensure that the funds are enough to cover prolonged use of the servers?

## Evaluation of the proposal

While it's not a simple upgrade to perform, it's one that can be very benefitial to have, so long as steps are taken to make it as secure as possible.  Not only do the cloud server tend to surpass typical on-premise capabilities, but it also allows for potential 24/7 access for any employees, allowing them to work from home. The largest problem with this proposal is how it can put the important data stored within those server at risk of being breached through the internet, which is especially a problem for the council as they would be handling the public's data as well. So, while it would be incredibly convinent for most people involved, it also means that protecting this data is something that needs to be invested into even more so than before.
