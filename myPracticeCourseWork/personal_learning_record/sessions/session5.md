#### Interrupts and Stacks
* An **interrupt** is a signal sent to the CPU that tells it to stop what it's currently doing, and run a specific routine.
* A **stack** is a simple, last-in, first-out, data structure used by a program for temporary storage
A **Link Register** stores the return address for a function:
* Single level storage so not ideal for nested functions (a function inside a function)
